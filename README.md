# Random Paragraph Generator

## 📝 Overview

**Random Paragraph Generator** is a web application built using **React.js** that generates random paragraphs of text with the click of a button. The app is designed to provide users with a quick way to generate filler text, making it useful for developers, designers, and content creators who need placeholder content.

With its simple and intuitive interface, **Random Paragraph Generator** allows users to instantly generate random text for use in mockups, prototypes, or testing.

🔗 [Live Demo](https://astr1cs.github.io/random-paragraph/)

## 🚀 Features

- **Generate Random Paragraphs**: Click the button to generate a random paragraph of text.
- **Simple Interface**: The app features a minimal design that focuses on ease of use.
- **Instant Results**: As soon as you click the button, a random paragraph is displayed on the screen.
- **Responsive Design**: The app adapts seamlessly to different screen sizes, making it mobile-friendly.
- **Fast and Lightweight**: Optimized for speed, providing instant results without delay.

## 🛠️ Technologies Used

- **React.js**: A JavaScript library for building dynamic user interfaces.
- **CSS**: Custom styles for a clean and responsive design.
- **HTML**: For structuring the app.
